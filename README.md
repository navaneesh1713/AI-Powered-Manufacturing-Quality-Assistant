# AI-Powered Manufacturing Quality Assistant

Manufacturing Quality Control & Generative Root-Cause Analysis system.

## Project Structure
- `frontend/` - React application built with Vite and Tailwind CSS
- `backend/` - Node.js Express server with PostgreSQL, MongoDB, and in-memory fallback support

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
